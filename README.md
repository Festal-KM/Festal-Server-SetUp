# Festal Server SetUp

共有開発サーバーの利用開始ガイド（2026-11-24）。Windows 利用者を主対象とする。Codex / Claude Code にこのリポジトリを読ませて進められる。

## 構成

利用者PC → Tailscale → Windows OpenSSH (22) → ProxyJump → 利用者専用 WSL2 Ubuntu 24.04 の SSH → VS Code Remote SSH / AI CLI / Rootless Docker。

Windows ホストは共有するが、Windows 標準ユーザー、WSL ディストリビューション、Linux ユーザー、認証情報、作業領域は利用者ごとに分離する。WSL のネットワークやポートは共有ホスト上で競合し得る。強固なテナント隔離を保証する構成ではない。

## 開始方法

1. 管理者に利用申請し、割当情報を受け取る（[管理者手順](docs/02-server-setup.md)）。
2. [利用者PC設定](docs/01-client-setup.md) を実行。
3. [開発環境設定](docs/03-development-setup.md) を実行。
4. 既存環境を引き継ぐ場合のみ [移行手順](docs/04-migration.md) を実行。
5. 問題があれば [トラブルシューティング](docs/05-troubleshooting.md) を参照。

## 管理者から個別に受け取る情報

- Tailscale 招待・接続先ホスト名または IP
- 自分専用の Windows ユーザー名、初回認証方法
- WSL ディストリビューション名、Linux ユーザー名
- 割当 SSH ポート、Windows と Linux の SSH ホスト鍵指紋
- 開発用ポートの割当、利用可能なリポジトリ、リソース制限
- 障害時の連絡先

本リポジトリは公開されているため、実値・秘密鍵・パスワード・トークン・内部ログをコミットしない。サーバー全体の初期構築ではなく、既設サーバーへの新規参加を対象とする。管理者手順の新規利用者への適用は個別検証が必要。
